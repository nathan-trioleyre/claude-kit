- Angular 21+: prefer standalone components, `inject()`, and signals over NgModules and constructor-heavy DI.
- Use built-in control flow (`@if`, `@for`, `@switch`) in templates.
- Unsubscribe with `takeUntilDestroyed()` or `toSignal()`; projects are zoneless by default, so keep state signal-friendly.
- Tests: Vitest is the default runner for new projects; `ng lint` requires `ng add angular-eslint` if not already configured.
