- Angular 21+: prefer standalone components, `inject()`, and signals over NgModules and constructor-heavy DI.
- Use built-in control flow (`@if`, `@for`, `@switch`) in templates; `*ngIf`/`*ngFor`/`*ngSwitch` are deprecated.
- Set `changeDetection: ChangeDetectionStrategy.OnPush` on components (it only becomes the default in Angular 22).
- Unsubscribe with `takeUntilDestroyed()` or `toSignal()`; zoneless is the default, so keep state signal-friendly.
- Tests: Vitest is the default runner for new projects (`ng test --no-watch` runs once; Karma is still supported).
- `ng lint` prompts to install `angular-eslint` if it is not configured yet.
