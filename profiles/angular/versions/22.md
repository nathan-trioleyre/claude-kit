- Angular 22 requires TypeScript >=6.0 <6.1 and Node.js ^22.22.3, ^24.15.0 or ^26.0.0 (angular.dev/reference/versions).
- Components with no `changeDetection` are now `OnPush`; set `ChangeDetectionStrategy.Eager` only to keep the old behavior.
- Signal Forms APIs graduated to the public API (22.0.0 changelog): prefer them for new forms.
- `@Service()` is a decorator for root-provided services (`@Service({autoProvided: false})` to opt out); `injectAsync` lazy-loads a service on demand.
- `@switch` supports exhaustive type checking via `@default never;` (switch expression must be a variable: use `@let` for signals/calls).
- Host directives are de-duplicated, and `in` variables now throw in template expressions (22.0.0 breaking changes).
- `withExperimentalPlatformNavigation()` (Router Navigation API) is labeled highly experimental: do not use in production.
