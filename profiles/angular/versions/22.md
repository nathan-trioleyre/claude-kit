- Angular 22 requires TypeScript >=6.0 <6.1 and Node.js ^22.22.3, ^24.15.0 or ^26.0.0 (angular.dev/reference/versions).
- Components default to `OnPush`; set `ChangeDetectionStrategy.Eager` only to keep the old behavior.
- Signal Forms APIs graduated to the public API: prefer them for new forms.
- `@Service()` is the stable shorthand for `@Injectable({providedIn: 'root'})` (`autoProvided: false` to scope it); `injectAsync` lazy-loads heavy auto-provided services.
- `@switch` accepts consecutive `@case` blocks and type-checks exhaustiveness on variables (use `@let` for signals).
- Host directives are de-duplicated, and `in` variables now throw in template expressions.
- The Router's Navigation API integration is experimental; do not enable it by default.
