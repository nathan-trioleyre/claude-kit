- Next.js 16 requires Node.js 20.9+ and TypeScript 5.1+; Turbopack is the default bundler (`next dev --webpack` / `next build --webpack` opt out).
- `next lint` is removed and `next build` no longer lints: run ESLint (or Biome) directly, e.g. `eslint .`.
- `middleware.ts` is deprecated: rename it to `proxy.ts` and export a function named `proxy` (Node.js runtime).
- `params`, `searchParams`, `cookies()`, `headers()` and `draftMode()` must be awaited; synchronous access is removed.
- Caching is opt-in: enable `cacheComponents` and use the `"use cache"` directive; `experimental.ppr` and `experimental.dynamicIO` are gone.
- `revalidateTag(tag, profile)` needs a `cacheLife` profile (single-argument form is deprecated); `updateTag()` (Server Actions only) gives read-your-writes.
- Parallel route slots need an explicit `default.js`; `next/image` local `src` with query strings needs `images.localPatterns`.
